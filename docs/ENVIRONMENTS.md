# DEV / TEST / PROD 约束

| 环境 | 目的 | 制品 | 成功定义 |
| --- | --- | --- | --- |
| DEV | 本地编辑和 PC 检查 | `dist/` 与临时 ZIP | 静态门禁和 PC 主流程 |
| TEST | 小红书容器真机验收 | 不可变 ZIP 与 SHA-256 | 必过用例完成真实手机测试 |
| PROD | 正式用户 | 原样晋级的 TEST ZIP | 平台确认发布并记录版本 ID |

- 运行时始终离线，不通过远程配置注入环境差异。
- 不在包内或日志中写入 token、账号、cookie、个人数据或平台凭据。
- 使用能力检测与真实错误处理，不按用户代理或机型名单分支。
- TEST 不等于网页预览；只有小红书容器内的真机结果才算 TEST。
